01 — the loop

Three seconds,
no copy-paste.

No website to open, no file to attach, no ⌘C ⌘V. The whole interaction is one held key.

  1. i

    Click into any text field

    An email, a ticket, a chat box, a code comment. If there’s a blinking cursor, Quotal can write there — it types through SendInput, exactly as if you had.

    caret: active
  2. ii

    Hold Right Alt and talk

    The pill fades in with a live level meter. 16 kHz from your default mic, ring-buffered so the first syllable never clips. Let go whenever.

    16 kHz · ring buffer
  3. iii

    Release — it’s pasted, cleaned

    Whisper transcribes locally, the hesitation filter and enhancer tidy the sentence, and the text lands at your cursor with a soft chime. The pill flashes Enhancing → Pasted and gets out of the way.

    chime 800 → 1200 Hz

02 — the cleanup

Spoken mess in.
Written sentence out.

People don’t talk in sentences. Quotal’s enhancer has three gears — switch them in Settings. These are the real rules, from cleaner.py and smart_enhancer.py.

you said“umm so aaj milte hai, okay uh?”

you get“So aaj milte hai, okay?”

you said“let’s meet at five, no wait, six pm”

you get“Let’s meet at 6 PM”

you said“send it over, badi, plz”

you get“Send it over, buddy, please”

Deterministic: filler shapes (um uh hmm ah er…) stripped, no wait / sorry / I mean keeps the correction, spoken shortcuts expanded (package dot json → package.json, control shift p → Ctrl+Shift+P). Careful exceptions: hum (“we” in Hindi) and err are never treated as filler.

you said“basically you know the meeting was like three things first intro then demo and follow up email”

you get“The meeting covered three things: 1) intro, 2) demo, 3) follow-up email.”

you said“i didnt sent the dont file yesterday”

you get“I didn’t send the file yesterday.”

A small local model (Qwen 2.5, half a billion parameters, ~390 MB) reflows grammar and lists, Wispr-Flow-style. Download it once from inside the dashboard; runs on CPU, happier on CUDA. Still zero cloud.

whisper heard“uh lets meet at five um no wait six”

you get“uh lets meet at five um no wait six”

Byte-for-byte Whisper output. Capitalisation and punctuation untouched. For transcripts, subtitles, or debugging the other two modes.

  • Listening — blue orb, live meter
  • Enhancing — violet, text shimmer
  • Pasted — green tick, then gone
  • drag it anywhere · double-click to re-centre · aura / ember / meter / orbit picked in Settings

03 — the engine room

Three voices.
All tenants, no landlord.

Quantized Whisper builds running under faster-whisper / CTranslate2. Switch live from the dashboard; the first run downloads the file, every run after is airplane-mode safe.

Currently on this machine: model_key: “small” · device: “cuda” — read straight from settings.json. CUDA is auto-detected with cuBLAS/cuDNN bundled in requirements.txt; no Toolkit install, graceful CPU fallback.

04 — setup

Ten minutes,
then never again.

  1. 1

    Prep Windows

    Python 3.10–3.12, 64-bit, with “Add to PATH” ticked. Edge WebView2 is already on Win 11 / recent Win 10 — otherwise grab Microsoft’s Evergreen bootstrapper. Then Settings → Privacy → Microphone → desktop-app access ON.

  2. 2

    Get the code

    Either download the exe below, or clone and install the deps yourself. NVIDIA folks: CUDA ships inside requirements.txt, nothing else to install.

    git clone https://github.com/PranavAnuvadia/Quotal.git
    python -m venv .venv
    .\.venv\Scripts\activate
    pip install -r requirements.txt
  3. 3

    First launch

    Double-click Quotal.exe. The tray icon appears, the dashboard opens, your model downloads once into the Hugging Face cache. Make the desktop shortcut while you’re at it:

    python make_shortcut.py
  4. 4

    Disappear into the tray

    Dashboard → Settings → Launch at startup. From then on Quotal boots with --silent: no console, no window, just the little “ by the clock. Open the dashboard from the tray whenever you want history or a model swap.

05 — asked often

Fair questions.

01Does my voice go to a server?

No. The microphone buffer goes to a Whisper model on your disk, then through a local cleanup pass. The only download is the model itself on first run. Unplug the ethernet after that and everything still works — that’s the whole point.

02Why does Task Manager say “Quotal”, not Python?

Quotal.exe hosts the interpreter inside a native GUI process (AppUserModelID Quotal.Voice.App), so windows, tray and workers group under Quotal’s name and icon. Side effect you’ll like: zero console popups, even at boot.

03I released the key and nothing pasted. Now what?

Three usual suspects: mic privacy toggle off for desktop apps; wrong default input device under Sound settings; or a too-short hold (under ~0.2 s is ignored). quotal.log will say which.

04Can I change Right Alt / F8?

Yes — they’re the VK_RMENU / VK_F8 constants near the top of app.py. Swap in any Win32 virtual-key code; Caps Lock (0x14) is a popular pick.

05The pill is somewhere weird. How do I get it back?

Double-click it while it’s visible and it snaps to bottom-centre. Or quit and set "pill_x": null, "pill_y": null in settings.json.

06Wispr Flow exists. Why this?

Flow is excellent — and cloud-tethered, subscription-priced, and Mac-first. Quotal is the Windows-native, offline, MIT-licensed answer: your GPU, your files, your hotkey, no account.
